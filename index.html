FEATURED PROJECT 2026

PULSE

Industrial Equipment Condition Monitoring System

PULSE is a condition-monitoring project exploring how equipment parameters such as pressure, temperature, vibration and flow rate can be continuously monitored to identify abnormal operating conditions.

The current prototype uses Python to simulate equipment readings, process the data and determine equipment status, while a Streamlit dashboard provides a live software monitoring interface.

The long-term concept involves integrating physical sensors and embedded hardware into an actual equipment-monitoring model.
